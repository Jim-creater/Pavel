# Павел из Тарса

Промо-сайт исторического сериала. Black Cobra Production.
Один сезон, восемь серий по 40–47 минут. Съёмки — Северная Осетия и Кисловодск.

Статическая страница: чистые HTML, CSS и JavaScript, без сборки и зависимостей.
Открывается двойным кликом по `index.html`.

---

## Что внутри

```
index.html              вся разметка
css/main.css            стили, палитра, сетка
js/main.js              прокрутка, появление блоков, вспышка на Дамаске
js/audio.js             звуковой слой
vendor/                 GSAP и ScrollTrigger, локально
fonts/                  Cormorant Garamond, Golos Text, Old Standard TT
assets/                 кадры визуальной разработки
assets/video/           горизонтальные лупы, mp4 и webm
assets/vertical/        вертикальные 9:16 для телефона и для монтажа тизера
assets/audio/           три темы и три звука интерфейса
```

## Главный приём

Сезон делится не на части, а на две температуры. До Дамаска палитра холодная,
после вспышки — тёплая. Сайт повторяет это буквально: в блоке «Поворот» он
переключает собственную палитру вместе с сериалом и дальше остаётся тёплым
до конца страницы.

Техника: `data-act="before|after"` на `<html>`, значения переключает
ScrollTrigger, все цвета живут в CSS-переменных.

## Звук

Выключен по умолчанию, включается кнопкой в шапке, выбор запоминается.
Три темы сменяются по главам — и меняются ровно в тот момент, когда
меняется палитра. Отсутствующий звуковой файл не ломает страницу:
этот слой просто молчит. Подробности — в `ЗВУК.md` предыдущей версии.

## Телефон

Вёрстка адаптивная. Первый экран и тизер подтягивают вертикальные 9:16
вместо горизонтальных: на экране стоймя кадр 2.39:1 превращается в полоску.
Переключение — по `(max-aspect-ratio: 3/4)` в CSS и в `js/main.js`.

## Доступность и производительность

- `prefers-reduced-motion` уважается: закрепление блока «Поворот» отключается,
  появления и дыхание кадров выключаются.
- Картинки грузятся лениво, до первого экрана долетает около 1,3 МБ.
- Видео грузятся только при подходе к экрану и встают на паузу,
  когда вкладка не активна.

## Публикация на GitHub Pages

1. Залить содержимое этой папки в корень репозитория.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. **Обязательно** поменять в `index.html` две строки на настоящий домен:

```html
<meta property="og:url" content="https://ваш-домен/">
<meta property="og:image" content="https://ваш-домен/assets/og.jpg">
```

Относительный путь к картинке превью понимают не все мессенджеры,
и без абсолютного адреса ссылка придёт без картинки.

Файл `.nojekyll` в корне нужен, чтобы GitHub Pages отдавал папки и файлы,
имена которых начинаются с подчёркивания, а не прятал их.

## Чего пока нет

- `assets/video/teaser.mp4` — самого тизера. Блок «Первый материал»
  показывает финальный кадр и подпись «Тизер в монтаже».
- `assets/audio/sfx-flash.mp3` — удар на вспышке синтезирован,
  стоит заменить настоящей записью.
